# Data Preparation & Validation

## Overview
This section covers the data preparation and validation process performed before conducting SQL-based product portfolio and investment analysis.

## Objectives
- Verify the structure of all five database tables.
- Check for duplicate records.
- Identify missing or NULL values.
- Validate primary and foreign key relationships.
- Check data consistency across tables.
- Ensure the dataset is suitable for analysis.

## Database Tables
1. Products
2. Sales
3. Market Data
4. Investments
5. Product Targets

## Validation Activities
- Table structure verification using `DESCRIBE`.
- Record count verification.
- Duplicate primary key checks.
- NULL value identification.
- Foreign key relationship checks.
- Year-wise data consistency checks.

## Tools Used
- MySQL
- SQL queries

## Outcome
The validation process helps identify data quality issues and improves the reliability of the subsequent sales, profitability, market growth, BCG classification, and investment analyses.

**Note:** The project uses simulated business data created for learning and portfolio demonstration.
